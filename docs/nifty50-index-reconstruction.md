Each date requires exactly 50 distinct verified securities, one input per security, one divisor and one official level. Records must carry HTTPS source metadata, a SHA-256-shaped digest, reviewer and ISO review date. These checks establish record completeness only; they do not authenticate sources or reviewer independence.\n\nThe divisor must already reflect official corporate-action adjustments.
